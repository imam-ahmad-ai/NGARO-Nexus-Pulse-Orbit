# NGARO Nexus Pulse Orbit

**INTEGRITY • QUALITY • QUANTITY**

NGARO Nexus Pulse Orbit is a modern digital platform that combines an
**E-Commerce Store** with an **ICT Academy / Learning Management System (LMS)**.

The platform is designed to provide customers with an online shopping
experience while giving students access to ICT courses, learning materials,
assessments, results, certificates, and other academic services.

---

## 🚀 Project Overview

NGARO Nexus Pulse Orbit is more than a conventional business website.

It is a scalable Laravel-based platform designed around multiple digital
services, including:

- 🛒 E-Commerce Store
- 🎓 ICT Academy
- 📚 Learning Management System (LMS)
- 👨‍🎓 Student Portal
- 👨‍🏫 Instructor Portal
- 📝 Assignments, Quizzes & Examinations
- 🏆 Certificate Management & Verification
- 🏢 SIWES Registration & Management
- 💳 Online Payment Integration
- 👨‍💼 Administration Dashboard
- 🔔 Notifications
- 📊 Business and Learning Management

---

## ✨ Main Features

### 🛍️ E-Commerce

Customers can:

- Browse products
- View product details
- Add products to cart
- Update cart quantities
- Checkout
- Provide delivery information
- Select payment methods
- Place orders
- Track orders
- View order history

Supported payment methods include:

- Paystack
- Bank Transfer
- Cash/Offline payment where configured

---

### 🎓 NGARO ICT Academy

- Software Engineering

- Python Programming

- Database Management
- Artificial Intelligence & Machine Learning
- Data Analysis
- Graphic Design
- Cloud Computing
- Ethical Hacking

- Digital Marketing

### 👨‍🎓 Student Portal

- View their profile

- Access learning materials
- Track learning progress
- Submit assignments
- Take quizzes
- Take examinations
- View results
- View certificates
